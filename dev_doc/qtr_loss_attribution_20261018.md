# QualityTrendRotationV1 回测亏损归因

日期：2026-10-18

范围：只读复核两组已完成的 FROZEN Dataset 回测，不调整策略、参数或历史记录。

## 结论

两组回测的全期总收益都约为 -60%，最大回撤分别为 63.50% 和 74.48%。亏损主要来自持仓的价格损失，尤其是 `MA60_EXIT` 退出的交易。现有执行记录没有显示卖出订单被拒、停牌/涨跌停拒绝或期末强平失败。证据支持“策略在部分市场阶段承受了很大的持仓损失”，但尚不足以排除所有特征口径或行情数据问题，也不能据此把亏损单独归结为市场环境。

两种资金规模不是简单的同比例组合。整手和现金约束使其持仓路径明显不同：1 万元组平均现金占比约 79.75%，2 万元组约 59.06%；两组只有 25 个完全相同的证券/买入日/卖出日区间。最大回撤发生日期也不同。因此 63.50% 与 74.48% 的差异与离散持仓路径相符，但不能只凭资金规模本身解释。

## 执行约束核查

通过 `BacktestRunRepository.diagnostic_orders()` 按买卖方向复核所有订单：

| 场景 | 买入订单 | 买入成交 / 拒绝 | 卖出订单 | 卖出成交 / 拒绝 |
|---|---:|---:|---:|---:|
| ¥10,000 | 692 | 49 / 643 | 48 | 48 / 0 |
| ¥20,000 | 663 | 89 / 574 | 86 | 86 / 0 |

买入拒绝主要是整手/现金容量不足（607、456）和达到最大持仓数（33、118）；¥10,000 另有 3 次 T+1 执行重算后无法按整手/现金约束成交。未发现卖出订单拒绝，也没有以停牌、涨跌停、不可卖出为原因的拒单。期末强制卖出模拟没有记录被阻断或缺价持仓；期末强平权益与市值权益差异分别约 ¥5.60 和 ¥17.79，不能解释约 60% 的全期损失。

因此，目前证据不支持“卖出因停牌或跌停持续失败”作为主要归因。拒绝记录几乎都在买入侧，且大量候选因资金和整手约束未成交。费用确实拖累结果，但毛价差损失远大于交易费用。

## 全期与样本外指标不能混用

两组全期都覆盖 1,204 个交易日；样本外部分为 246 个交易日。样本外收益分别为 +0.7367% 和 +5.5234%，同期基准 +9.9121%，样本外超额收益分别为 -9.1754 和 -4.3887 个百分点。它们描述的是样本外子区间，不能解释全期 -60% 的总收益；全期超额收益是策略 -5.1456% 基准的相同全期差值。

## 归因判断与边界

1. **有证据的主要贡献**：`MA60_EXIT` 交易净损失最大；单只股票出现约 45% 的单笔损失；2022 年损失远大于同期基准。
2. **有证据的执行影响**：100 股整手、初始资金及最大持仓约束导致较多候选买单未成交，且资金规模改变了持仓数量和在场时间。它影响路径，但当前证据不能把亏损归因于执行故障。
3. **待验证的策略机制解释**：按 60 日动量排序并在价格跌破 MA60 后退出，可能在快速反转中买在较强趋势后段、并于下行阶段承受较大回撤。这是与策略规则和交易结果一致的假设，不是已证明的因果结论。
4. **尚未排除**：冻结价格/复权特征的准确性、财务质量输入的 PIT 语义、个别公司行为对其他持仓的影响、回测中的所有估值/执行细节。当前结果不能单独证明代码错误，也不能证明策略长期无效。

本轮没有调参、替换策略或修改历史结果。探索性诊断文件位于本机 `%TEMP%`：`qtr-10k-diagnostic-20261018.json` 和 `qtr-20k-diagnostic-20261018.json`，版本 `backtest-diagnostics-v2`。
